## 🧠 О проекте

**SignQazaq Pro** — это портативный переводчик казахского жестового языка (КЖЯ), работающий в режиме реального времени. Проект разрабатывается для встраиваемой платы **UNIHIKER K10**, которая позволяет носить устройство с собой и мгновенно переводить жесты глухонемых на казахском языке в текст.

### Ключевые цели:
- 🖐 Распознавать жесты казахского жестового алфавита (А, Ә, Б, В...)
- 📱 Работать автономно на компактном устройстве UNIHIKER K10
- 📊 Позволять пользователям самостоятельно собирать и расширять датасет
- 🤖 Обучать лёгкую ML-модель, работающую без GPU

## 🔧 Требования

### Для разработки (Mac)
| Компонент | Версия |
|-----------|--------|
| macOS | 12.0+ (Monterey и выше) |
| Python | **3.11** (обязательно — MediaPipe не поддерживает 3.13+) |

### Для деплоя (UNIHIKER K10)
| Компонент | Версия |
|-----------|--------|
| Python | 3.9+ |
| ОС | Debian Linux (встроенная) |
| RAM | 512 MB+ |
| Камера | USB или встроенная |

## ⚙️ Установка

### 1. Клонировать репозиторий
```bash
git clone https://github.com/your-username/SignQazaq.git
cd SignQazaq
```

### 2. Установить Python 3.11 (если не установлен)
```bash
# Через Homebrew (рекомендуется)
brew install python@3.11
```

### 3. Создать виртуальное окружение
```bash
/opt/homebrew/bin/python3.11 -m venv venv
```

### 4. Установить зависимости
```bash
venv/bin/pip install --upgrade pip
venv/bin/pip install -r requirements.txt
```

### 5. Проверить установку
```bash
venv/bin/python -c "import mediapipe, cv2, numpy; print('✅ Всё готово!')"
```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `S` | Сохранить текущий жест в датасет |
| `1` — `9` | Выбрать метку жеста (А, Ә, Б...) |
| `ESC` / `Q` | Выйти из программы |

## 📊 Сбор датасета

Датасет сохраняется автоматически в `dataset/landmarks.csv`.

### Формат записи:
```
label, x0, y0, z0, x1, y1, z1, ..., x20, y20, z20
```
- `label` — числовой класс жеста (1 = А, 2 = Ә, ...)
- 21 точка × 3 координаты (x, y, z) = **63 признака**

### Рекомендуемый процесс сбора:
```
1. Выбери метку: нажми [1] (жест "А")
2. Покажи жест "А" перед камерой
3. Нажимай [S] 50-100 раз (меняй угол, освещение)
4. Нажми [2] (жест "Ә") и повтори
5. Продолжай для всех букв алфавита
```

> 💡 **Рекомендация:** минимум 50 образцов на класс для хорошего качества модели.
