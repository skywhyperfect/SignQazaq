# 🤟 SignQazaq Pro

**SignQazaq Pro** — это инновационный проект портативного переводчика казахского жестового языка (КЖЯ). Система использует технологии компьютерного зрения и глубокого обучения для распознавания жестов в реальном времени и их перевода в текст и голос.

---

## ✨ Основные возможности (v0.4)

- **🖐 Распознавание рук**: Использование самого современного MediaPipe Tasks API для точного трекинга 21 ключевой точки руки.
- **🔡 Казахский алфавит**: Встроенный геометрический классификатор для букв казахского жестового языка.
- **📝 Транскрипция**: Автоматическое накопление букв в слова и предложения с поддержкой авто-пробелов.
- **🔊 Озвучка (TTS)**: Мгновенная озвучка распознанного текста с использованием казахского голоса (*Aru*).
- **🔋 Оптимизация**: Работает в реальном времени даже на мобильных процессорах (оптимизировано под ARM).

---

## 🛠 Технологический стек

- **Язык**: Python 3.11 (рекомендуется)
- **Зрение**: MediaPipe Tasks API 0.10.x
- **Графика**: OpenCV
- **Голос**: macOS `say` (Aru / kk-KZ)
- **Платформа**: macOS (разработка) / UNIHIKER/Linux (деплой)

## 🚀 Быстрый запуск

### 1. Подготовка системы
Убедитесь, что у вас установлен **Python 3.11** (MediaPipe на Mac пока не поддерживает 3.13+).

### 2. Установка проекта
```bash
# Клонируйте проект и перейдите в папку
cd SignQazaq

# Создайте виртуальное окружение
/opt/homebrew/bin/python3.11 -m venv venv

# Обновите pip и установите зависимости
venv/bin/pip install --upgrade pip
venv/bin/pip install -r requirements.txt
```

### 3. Запуск
Просто запустите скрипт автоматизации:
```bash
./run.sh
```

## 🎮 Управление в приложении

| Клавиша | Действие |
|:---:|:---|
| **Удержание жеста** | Удерживайте жест 20 кадров для добавления буквы в строку |
| **Пауза 1.5с** | Программа автоматически добавит пробел, если убрать руку |
| `ENTER` | Озвучить всю накопленную строку целиком |
| `BACKSPACE` | Удалить последний символ |
| `C` | Полностью очистить окно транскрипции |
| `ESC` / `Q` | Выход из программы |

## 📁 Структура проекта

- `main.py`: Ядро приложения, UI и логика транскрипции.
- `gesture_engine.py`: Логика распознавания жестов (геометрический анализ).
- `tts_engine.py`: Асинхронный движок озвучки (Text-to-Speech).
- `models/`: Место для хранения MediaPipe моделей (`.task`).
- `dataset/`: Папка для сбора данных для будущего обучения ML-моделей.
