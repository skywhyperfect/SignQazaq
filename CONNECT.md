# 🔌 Гайд по подключению к UNIHIKER K10

Ваша плата **UNIHIKER K10** построена на чипе **ESP32-S3**. Это мощный микроконтроллер, но он отличается от Linux-версии (M10).

---

## 1. Подключение к компьютеру

1.  **Порт**: Используйте разъем **Type-C** на боковой панели.
2.  **Режим**: При подключении к Mac плата обычно определяется как последовательный порт (COM-порт / tty.usbmodem).
3.  **Драйверы**: Если порт не виден, установите драйверы для **CH340** или **CP210x** (в зависимости от ревизии, обычно K10 работает сразу).

---

## 2. Работа через Mind+ (Рекомендуется)

Самый простой способ быстро запустить код:
1.  Скачайте и установите **Mind+** [http://mindplus.cc](http://mindplus.cc).
2.  Переключитесь в режим **"Python"** (в правом верхнем углу).
3.  Нажмите **"Cубъекты"** (Devices) → **"Платформа"** → Выберите **UNIHIKER K10**.
4.  Нажмите **"Подключить устройство"**.

---

## 3. Архитектура SignQazaq Pro для K10

Так как ESP32 не может запустить MediaPipe, мы используем схему **"Бридж"**:

- **Mac (Brain)**: Запускает наш текущий `main.py`. Он ловит видео, распознает жест и делает озвучку.
- **USB Кабель**: Передает текстовую строку (букву) на плату.
- **K10 (Display)**: Принимает текст по Serial и отображает его крупным шрифтом на своем экране 320x240.

---

## 4. Как запустить связь
Чтобы K10 "услышал" ваш Mac, нужно загрузить в саму плату небольшой скрипт на MicroPython.

### Код для K10 (загрузить через Mind+ или Thonny):
```python
from unihiker_k10 import screen
import sys

screen.clear()
screen.draw_text("SignQazaq Pro", x=10, y=10, size=20, color=(0, 255, 0))
screen.draw_text("Күту...", x=10, y=50, size=15)

while True:
    # Ждем данных от Mac
    line = sys.stdin.readline().strip()
    if line:
        screen.clear()
        screen.draw_text("Распознано:", x=10, y=10, size=15)
        # Отрисовка буквы в центре
        screen.draw_text(line, x=100, y=80, size=80, color=(255, 255, 0))
```

## 5. Настройка Mac
Вам нужно будет установить библиотеку `pyserial` внутри вашего `venv` на Mac:
```bash
venv/bin/pip install pyserial
```
